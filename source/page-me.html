技术集成

i

提示：技术集成可以和业务入驻并行进行，无需等待产品开通审核完成。建议先使用沙箱环境完成集成和测试，沙箱环境不使用真实资金，可以放心调试。

手动 SDK 集成

  1. 1
    配置沙箱密钥

    将以下密钥配置到项目环境变量中

    沙箱环境（测试用）
    AIPAY_APP_ID=2024001234567890 # 沙箱应用公钥 AIPAY_PUBLIC_KEY=MIIBIjANBgkqhk... # JAVA 语言私钥 AIPAY_PRIVATE_KEY=MIIEvQIBADANBg... # 非 JAVA 语言私钥 AIPAY_PRIVATE_PKCS_KEY=MIIEowIBAA... # 沙箱支付宝公钥 AIPAY_ALIPAY_PUBLIC_KEY=MIIBIjANBgkqhk...
  2. 2
    修改网关地址

    将网关地址修改为沙箱地址

    以java代码为例
    AlipayClient alipayClient = new DefaultAlipayClient("https://openapi-sandbox.dl.alipaydev.com/gateway.do",AIPAY_APP_ID,AIPAY_PRIVATE_KEY,"json","UTF-8",AIPAY_PUBLIC_KEY,"RSA2");
  3. 3
    参考文档进行集成

    详情见 当前产品产品接入指南

沙箱环境无需使用真实资金。所有交易均为模拟数据，不会产生任何实际费用，可以放心反复测试。

线上验证

把代码里的沙箱配置换成线上真实配置,然后发起一笔真实交易,确认支付全链路在线上可以正常使用。

找到代码中的沙箱密钥

在你的代码或环境变量中搜索以下沙箱，将它们替换为下方的线上值：

沙箱环境（需要被替换的值）
AIPAY_APP_ID=2024001234567890 # 沙箱应用公钥 AIPAY_PUBLIC_KEY=MIIBIjANBgkqhk... # JAVA 语言私钥 AIPAY_PRIVATE_KEY=MIIEvQIBADANBg... # 非 JAVA 语言私钥 AIPAY_PRIVATE_PKCS_KEY=MIIEowIBAA... # 沙箱支付宝公钥 AIPAY_ALIPAY_PUBLIC_KEY=MIIBIjANBgkqhk...

替换为线上密钥

线上环境（替换目标）
AIPAY_APP_ID=2024001234567890 # 线上应用公钥 AIPAY_PUBLIC_KEY=正在加载... # 线上 JAVA 语言私钥 AIPAY_PRIVATE_KEY=（需自行配置线上 JAVA 语言私钥） # 线上非 JAVA 语言私钥 AIPAY_PRIVATE_PKCS_KEY=（需自行配置线上非 JAVA 语言私钥） # 线上支付宝公钥 AIPAY_ALIPAY_PUBLIC_KEY=正在加载...

切换步骤

  1. 将环境变量中的 AIPAY_APP_ID、AIPAY_PUBLIC_KEY、AIPAY_PRIVATE_KEY、AIPAY_PRIVATE_PKCS_KEY、AIPAY_ALIPAY_PUBLIC_KEY 替换为上方线上值
  2. 确认网关地址已配置为正式网关地址：https://openapi.alipay.com/gateway.do
  3. 确认异步通知地址已配置为线上域名
  4. 部署应用到生产服务器

验证清单

  • 发起一笔真实支付请求（可使用小金额如 0.01 元）
  • 使用支付宝 APP 扫码 或者 输入账号/密码 完成支付
  • 异步通知正常接收（可选）
  • 测试退款流程（可选）
  • 发起一笔真实支付请求（可使用小金额如 0.01 元）
  • 通过你的 Agent 完成付款（查看详情）
  • 异步通知正常接收（可选）
  • 测试退款流程（可选）
